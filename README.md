Este es un software encargado en la gestión de citas para tener un control organizado de manera de que sepan si el cliente asiste o no a sus clase
Funcionamiento:
Este software consta de 3 roles
1. Administrador: Tiene como funcionalidad de agregar clientes, instructores, vehículos y citas
2. Instructor: Este tiene como funcionalidad ver que clases tiene por dar y también puede actualizar el tema de las observaciones que hayan ocurrido en la clase
3. Cliente: Este tiene como funcionalidad solo ver que citas tiene programadas
¿Como se usa?
Este proyecto consta de varios menús cada uno para su rol y con sus funcionalidades
El proyecto se encarga de tener un uso de sistema organizad
